# Codeium / Windsurf (Exafunction)

**Developer:** Exafunction  
**Type:** AI coding assistant & agentic editor  
**Website:** https://codeium.com / https://windsurf.com

## Overview
Codeium provides free AI code completions and a chat assistant across 70+ languages. Windsurf is Exafunction's AI-native IDE built on VS Code, featuring the "Cascade" agentic flow for autonomous multi-file editing and terminal usage.

## Capabilities
- Fast, free AI code completions
- Chat for code generation and Q&A
- Windsurf Cascade agent: autonomous multi-file edits with terminal access
- Deep context awareness via semantic search
- Supports VS Code, JetBrains, Vim, and more
