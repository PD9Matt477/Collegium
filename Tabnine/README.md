# Tabnine

**Developer:** Tabnine  
**Type:** AI coding assistant  
**Website:** https://www.tabnine.com

## Overview
Tabnine is an AI code completion tool supporting 30+ languages and all major IDEs. It offers both cloud-based and fully on-premises deployment options, making it popular in privacy-conscious enterprise environments.

## Capabilities
- AI-powered inline code completions
- Whole-line and full-function suggestions
- Team learning from private codebases
- On-premises / self-hosted deployment
- IDE plugins for VS Code, JetBrains, Vim, Emacs, and more
