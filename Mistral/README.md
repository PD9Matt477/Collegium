# Mistral AI

**Developer:** Mistral AI  
**Type:** Open-weight AI models & coding assistant  
**Website:** https://mistral.ai / https://console.mistral.ai

## Overview
Mistral AI produces high-efficiency open-weight LLMs (Mistral 7B, Mixtral 8x7B, Mistral Large, Codestral) and offers them via a commercial API. Codestral is Mistral's dedicated code model supporting 80+ programming languages.

## Capabilities
- Code generation, completion, and debugging (Codestral)
- Fill-in-the-middle (FIM) code completion
- API and self-hosted deployment
- Agentic use via Mistral's function-calling API
- Multilingual code support (80+ languages)
