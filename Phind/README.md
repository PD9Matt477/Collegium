# Phind

**Developer:** Phind  
**Type:** AI search engine & coding assistant  
**Website:** https://www.phind.com

## Overview
Phind is an AI-powered developer search engine and coding assistant built on top of GPT-4 and its own Phind-CodeLlama models. It specialises in answering programming questions with cited web sources and generating complete code solutions.

## Capabilities
- AI-powered developer search with cited sources
- Code generation and step-by-step debugging
- Phind-CodeLlama: custom open-source code model (34B)
- VS Code extension for in-editor assistance
- Context-aware answers using real-time web search
