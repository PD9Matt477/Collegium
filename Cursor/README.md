# Cursor

**Developer:** Anysphere  
**Type:** AI-native code editor & agent  
**Website:** https://www.cursor.com

## Overview
Cursor is an AI-first fork of VS Code that embeds LLM capabilities (GPT-4, Claude, custom models) directly into the editor. Its Composer / Agent mode can autonomously write, edit, and run multi-file changes.

## Capabilities
- AI-powered inline completions and chat
- Composer: multi-file, multi-step autonomous edits
- Agent mode: runs terminal commands, reads docs, iterates on errors
- Codebase-aware context retrieval (@ symbols, docs indexing)
- Compatible with any language or framework
