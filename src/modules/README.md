# src/modules/

Self-contained feature modules.  Each module owns its own application-layer logic and communicates with `src/core/` through defined interfaces.

| Sub-directory | Description |
|---|---|
| `admissions/` | Application intake, document review, and enrollment onboarding |
| `academics/` | Curriculum management, course delivery resources, and grade reporting |
| `finance/` | Tuition billing, scholarship management, and grant tracking |
| `student-services/` | Academic advising appointments and counseling resources |
