# Grok (xAI)

**Developer:** xAI (Elon Musk)  
**Type:** AI assistant & coding model  
**Website:** https://x.ai / https://grok.x.ai

## Overview
Grok is xAI's LLM, integrated into X (Twitter) and available via API. Grok 2 and Grok 3 include strong coding capabilities and real-time internet access, making them suitable for code generation with up-to-date context.

## Capabilities
- Code generation and debugging
- Real-time web search for current documentation/APIs
- Function calling and tool use via API
- Image understanding (multimodal)
- Available via xAI API and X Premium subscriptions
