# Claude (Anthropic)

**Developer:** Anthropic  
**Type:** AI assistant & coding agent  
**Website:** https://www.anthropic.com / https://claude.ai

## Overview
Claude is Anthropic's family of large language models (Claude 3, Claude 3.5 Sonnet, Claude 4, etc.). It is widely used for code generation, analysis, and autonomous agentic tasks via the Claude API and tool-use / computer-use features.

## Capabilities
- Code generation, review, and debugging
- Agentic tool-use (bash, file I/O, browser) via Claude Computer Use
- Multi-turn conversation and long-context reasoning (up to 200k tokens)
- Autonomous software engineering tasks (SWE-bench top performer)
- API integration with MCP (Model Context Protocol)
