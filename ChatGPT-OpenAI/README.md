# ChatGPT / GPT-4 (OpenAI)

**Developer:** OpenAI  
**Type:** AI assistant & coding agent  
**Website:** https://openai.com / https://chatgpt.com

## Overview
OpenAI's GPT-4 family (including GPT-4o, GPT-4.1, o1, o3, o4-mini) powers ChatGPT and the Assistants / Agents SDK. It supports code generation, execution via Code Interpreter, and autonomous multi-step task completion.

## Capabilities
- Code generation, explanation, and debugging
- Code Interpreter (sandboxed Python execution inside ChatGPT)
- Autonomous agents via the OpenAI Agents SDK / Responses API
- Function / tool calling for external integrations
- Vision capabilities for UI-to-code workflows
