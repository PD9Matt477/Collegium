# GitHub Copilot

**Developer:** GitHub / Microsoft  
**Type:** AI coding assistant & agent  
**Website:** https://github.com/features/copilot

## Overview
GitHub Copilot is an AI-powered coding assistant built on OpenAI Codex / GPT-4. It integrates directly into editors (VS Code, JetBrains, Neovim, etc.) to provide inline code completions, chat-based generation, and — via Copilot Workspace / Copilot Coding Agent — full autonomous task execution within a repository.

## Capabilities
- Inline code suggestions and completions
- Multi-file edits via Copilot Edits / Workspace
- Autonomous coding agent (Copilot Coding Agent / Task Agent)
- Chat interface for code explanation, refactoring, and generation
- Pull-request summarisation and review
