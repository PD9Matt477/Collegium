# DeepSeek Coder

**Developer:** DeepSeek AI  
**Type:** Open-source AI coding model  
**Website:** https://www.deepseek.com / https://github.com/deepseek-ai/DeepSeek-Coder

## Overview
DeepSeek Coder is a family of open-source code-focused LLMs (1B–33B parameters) trained on 2T tokens of code and natural language. DeepSeek-V2 and DeepSeek-R1 extend capabilities to general reasoning and agentic use cases.

## Capabilities
- Code generation, completion, and debugging
- Repository-level code completion
- Fill-in-the-middle (FIM) support
- Available for local / self-hosted deployment
- Strong performance on HumanEval and SWE-bench benchmarks
