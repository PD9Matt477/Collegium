# Code Llama (Meta AI)

**Developer:** Meta AI  
**Type:** Open-source AI coding model  
**Website:** https://ai.meta.com/blog/code-llama-large-language-model-coding/

## Overview
Code Llama is Meta's family of open-source, code-specialised LLMs built on top of Llama 2/3. Available in multiple sizes (7B–70B+), it can be run locally or self-hosted and supports code generation, completion, and infilling across many languages.

## Capabilities
- Code generation, completion, and infill
- Available in Base, Instruct, and Python-optimised variants
- Runs locally (Ollama, llama.cpp, etc.) — no API required
- 16k context window (32k in some variants)
- Foundation for many community fine-tunes and tools
