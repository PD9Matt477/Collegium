# Amazon Q / CodeWhisperer (AWS)

**Developer:** Amazon Web Services  
**Type:** AI coding assistant & agent  
**Website:** https://aws.amazon.com/q/developer/

## Overview
Amazon Q Developer (formerly CodeWhisperer) is AWS's AI coding assistant. It provides real-time code suggestions, security scanning, and autonomous feature development tasks within IDEs and the AWS console.

## Capabilities
- Inline code completions (optimised for AWS SDKs and services)
- Security vulnerability scanning
- Autonomous multi-step feature development (Amazon Q Developer Agent)
- CLI assistance and natural-language-to-AWS-CLI translation
- Integration with VS Code, JetBrains, and the AWS Console
