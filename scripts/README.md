# scripts/

Operational and automation scripts.

| Sub-directory | Description |
|---|---|
| `build/ci/` | Continuous-integration pipeline scripts (lint, test, build steps) |
| `build/release/` | Release tagging and changelog generation scripts |
| `deploy/staging/` | Deployment automation targeting the staging environment |
| `deploy/production/` | Deployment automation targeting the production environment |
| `maintenance/backup/` | Database and file-storage backup scripts |
| `maintenance/migration/` | One-off data-migration scripts (separate from ORM migrations) |
