# Gemini (Google DeepMind)

**Developer:** Google DeepMind  
**Type:** AI assistant & coding agent  
**Website:** https://gemini.google.com / https://ai.google.dev

## Overview
Gemini is Google's flagship multimodal LLM family (Gemini 1.5 Pro, Gemini 2.0, Gemini 2.5 Pro). It powers Google AI Studio, Vertex AI, and coding integrations in Android Studio, Firebase, and more.

## Capabilities
- Code generation, review, and debugging
- Very long context window (up to 1M tokens in Gemini 1.5 Pro)
- Autonomous agentic tasks via Gemini 2.0 agent mode
- Deep Search / reasoning mode (Gemini 2.5)
- Tight integration with Google Cloud and Firebase
