## Overview
Replit's AI features (Ghostwriter, Replit Agent) are deeply integrated into the Replit online IDE. The Replit Agent can build and deploy entire applications from a natural-language description directly in the browser.

## Capabilities
- Inline code completions and chat
- Replit Agent: builds full apps from a prompt (frontend + backend + DB)
- Runs and deploys code instantly in the Replit environment
- Supports 50+ languages in a browser-based IDE
- Integrates with Replit's hosting and database services
